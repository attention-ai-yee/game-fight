# Game Fight（暂定名）

抖音小游戏 · 竖屏 · 挂机割草 + 三人接力 · 纯广告变现。

一条通道，三个英雄轮流上场。放着不管就自动割草；想爽的时候点一下换人，把上一个人留下的印记一口气引爆。
